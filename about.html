About EasyTrip

Travel ideas, shaped into one learning experience

EasyTrip is a university web project exploring how destinations, stays, and transport planning can come together in a clear, accessible interface.

See what EasyTrip is

What EasyTrip is

EasyTrip brings several travel-planning ideas into one student-built website. Visitors can explore destinations by season, browse sample accommodation, and prepare flight or ground-transport searches through interactive frontend experiences.

The current version focuses on interface design, responsive behavior, accessibility, and clear user flows. Backend and database features can be connected as the programming project develops.

Why we built it

Travel planning creates useful programming challenges: organizing information, validating forms, connecting pages, designing responsive interfaces, and eventually storing and retrieving data.

EasyTrip turns those challenges into one coherent academic project.

Skills in focus

  • Structuring a multi-page website with shared navigation
  • Building consistent, reusable interface patterns
  • Designing forms, filters and browsing experiences
  • Making pages accessible and responsive on any screen
  • Preparing the frontend for backend and database work

What guides the experience

Four principles shape every page, from the main menu to the planners.

Clarity
Important actions and information should be easy to find, with plain labels and one clear next step.
Consistency
Pages share the same navigation, buttons and layout rules, so the site feels like one product.
Accessibility
Navigation and content should work with a keyboard, a screen reader, zoomed text and small screens.
Honesty
Prototypes say what they are. Sample prices and planners never pretend to offer live data or bookings.

Built as a university project

EasyTrip was created as a programming project to combine interface design, frontend development, form behavior, and future database work in one connected website.

Today

  • Static pages built with HTML, CSS and JavaScript
  • Sample hotels, chalets, prices and routes
  • Forms that check what you enter in the browser

Possible next steps

  • Listings loaded from a database
  • Accounts and sign-in
  • Reservations saved on a server
  • Admin tools to manage content
